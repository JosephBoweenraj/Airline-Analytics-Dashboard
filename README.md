📊 Flight Booking Analytics Dashboard | Power BI

📌 Project Overview

This project is an interactive Flight Booking Analytics Dashboard developed using Microsoft Power BI to analyze airline bookings, passenger behavior, revenue performance, payment methods, booking status, and route-level performance.

The dashboard provides an executive-level overview of key business KPIs and enables users to explore booking and revenue patterns using interactive filters.

🛠️ Tools & Technologies
Power BI
Power Query
DAX
Microsoft Excel
Data Modeling
Data Visualization
